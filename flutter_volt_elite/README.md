# VoltElite — EV Charging Super App (Flutter Edition)

This is the complete, production-ready Flutter implementation of **VoltElite**, featuring:
- **Scan QR to Charge**: Viewfinder laser sweep animation, flashlight toggle, manual entry, and quick 1-tap demo scan presets.
- **Provider Aggregator**: Tata Power, ChargeZone, Statiq, Jio-bp, Zeon, BPCL, Kazam, Ather Grid.
- **Charger Verification**: Availability check, power & tariff display, and automatic EV vehicle connector compatibility verification.
- **Multi-Rail Payment**: UPI (GPay, PhonePe, Paytm), VoltElite Wallet, Credit/Debit Card, Pre-Authorization Hold.
- **Live Charging Telemetry**: Real-time animated battery progress gauge, energy delivered (kWh), and cost accumulation.
- **Digital Receipts & History**: Itemized invoice generation and persistent charging history.

## How to Run
```bash
# 1. Ensure Flutter is installed (https://flutter.dev)
flutter doctor

# 2. Get dependencies
flutter pub get

# 3. Run the app on any device (iOS, Android, macOS, Web)
flutter run
```
